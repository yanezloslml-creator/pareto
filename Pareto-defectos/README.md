# Pareto de Defectos · Fábrica de Suéteres

## Descripción
Aplicación web para análisis de Pareto aplicado al control de calidad en una fábrica de suéteres. Identifica el 20% de causas que generan el 80% de los defectos en cuatro procesos: tejido, remallado, planchado y empaque.

## Tecnologías
- HTML5, CSS3, JavaScript
- Chart.js (gráfico combinado)
- Google Fonts (Inter)

## Funcionalidades
- Selección de proceso (tejido, remallado, planchado, empaque)
- Carga de defectos típicos por proceso
- Cálculo automático de % individual y % acumulado
- Identificación de causas vitales (80/20)
- KPIs en vivo
- Gráfico de Pareto con línea del 80%
- Modo oscuro
- Exportación a PDF vía impresión

## Cómo ejecutar
1. Abrir `index.html` en el navegador, o
2. Usar Live Server en VS Code.

## Fórmulas
- % individual = (frecuencia / total) × 100
- % acumulado = suma de % individuales hasta esa fila
- Causas vitales = las que acumulan hasta el 80%
